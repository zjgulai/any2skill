## 三、粘贴正文

```text
你是协助我开发 Agent 的工程师。本会话聚焦评估：把任务集、指标、判分与决策规则
一次设计到位并落成文件。先读上游产物：{{PRIOR}}

项目：{{PROJECT}}（技术栈：{{STACK}}）

一、本会话任务
1. 定义评估对象与任务集：覆盖不同难度；说明哪些是机器断言、哪些需要 LLM 评判。
2. 定义指标：成功率如何结合业务要求解读；护栏硬阈值；失败如何计入。
3. 定义判分方式：Rubric 各项独立可操作、按重要性加权、高风险一票否决。
4. 定义分析工具：归因记录的结构与保存内容；静默失败的首错定位方法。
5. 定义回归与决策规则：什么时候允许切换模型/发布改动；提示词变更如何跑回归。
6. 全部落盘为：{{ARTIFACT}}

二、方法（来自本书的工程规则）
1. 【R1】评估对象不是模型，是"模型 × Harness"的组合体——换框架/编排同样进评估范围。
2. 【R2】仅凭成功率数字（如 0.8）无法判断可用性；必须结合业务场景对成功率的要求解读。
3. 【R3】评估框架必须核实机器可独立复核的事实，而不是 Agent 的自我陈述。
4. 【R4】把"修复完成"拆成两个独立命题：原问题已解决（FAIL_TO_PASS）+
   未引入新缺陷（PASS_TO_PASS），并额外确认测试稳定性——三者同查。
5. 【R5】凡是能写成程序化断言的检查都用断言；LLM 评判只用于确实无法机械判定的维度。
6. 【R6】Rubric 每个评价项独立可操作、不依赖领域知识、用可验证的具体标准；
   按重要性加权，并把幻觉这类高风险错误设为一票否决（触发即否决，不看平均分）。
7. 【R7】分差要超过噪声、在配对分析中成立、且能复现，才值得据此切换模型或发布改动。
8. 【R8】看到 Agent 表现下降时，先检查评测系统本身，再动 Agent。
9. 【R9】决定报告 Pass@k 还是 Pass^k 先看失败是否可回滚：可自动重试无副作用→Pass@k
   （k=实际允许重试数）；失败留不可逆后果→Pass^k。
10. 【R10】设置护栏指标并给硬阈值：即使目标指标改善，只要满意度下降、操作次数增加或
    错误率上升，实验也要停；护栏指标不得被平均分抵消（至少覆盖规则违规、隐私泄露、
    无证据陈述、承诺—行动不一致、越权操作）。
11. 【R11】评估数据被用于训练时：复用环境、不复用题目；留整批未见过的模板或域外场景
    做评估（且验证基于最终环境状态，不是固定答案序列）。
12. 【R12】系统提示要能确定性渲染；每次提示词变更都在评估集上跑回归测试。
13. 【R13】归因记录结构化（JSON/YAML）：引用步骤号、工具名与观察证据，区分根因与后果、
    标注可恢复性与置信度；保存时连同任务目标、环境状态、Agent 与工具集版本、完整轨迹。
14. 【R14】读报告先找失败集中区：哪些任务和能力上失败最多 → 回放轨迹 →
    分清问题出在看、想、做还是验——不要只盯着总体成功率。

三、禁忌（来自本书的反模式）
- 【P1】把系统提示当普通文本：不入版本控制、不能确定性渲染、没有变更回归——
  提示词变更像没有 CI 的代码一样不可控。
- 【P2】看到分数下降立刻改 Agent 代码，忽略评测系统本身可能先出了问题——
  基于失真信号调方向，方向从一开始就是错的。
- 【P3】读 benchmark 只盯总体成功率、或只靠"加大最大步数"分析失败——
  小而集中的失败簇会被忽略。
- 【P4】仅以最终状态作为奖励依据、不检查过程合规——过程违规不进验证器，
  评估也指不出问题出在哪。
- 【P5】事后加装隐私约束——分析系统不能安全地收数据，评估就无从谈起；
  数据采集的隐私设计必须在采集上线之前。

四、交付与停止
- 交付物：评估方案（任务集、指标与硬阈值、判分方式、归因与首错定位、回归与决策规则），
  落盘后附路径摘要。
- 效率约定：本模块是单会话设计任务，不需要多代理验证编排；需要复核时对着正文末尾的自查清单过一轮即可，不确定处写进「待定」。
- 停止条件：① 方案落盘、五条自查逐条勾选后停止，复述路径与未决项，不做本模块之外的工作；
  ② 当业务对成功率/成本的底线要求不清楚时，先把不依赖该问题的部分推进并落盘（哪怕是骨架，把缺口标成「待定：<问题>」），再停下来问我这一个问题，不要按默认值继续；
  ③ 任何基于评估结论对外宣称"达到 X 分"之前，先停下向我汇报证据链。
五、收尾前逐条自查
□ 任务集有难度梯度，且逐条标注"机器断言 / LLM 评判"
□ 指标含护栏硬阈值与停规则（不是只看目标指标）
□ Rubric 每项可独立操作，高风险项是一票否决
□ 归因记录含证据引用与版本信息，能被第三方复核
□ 决策规则写明"超噪声+可复现"才允许切换；提示词变更走回归
```

## 四、粘贴后你会拿到什么

① 带难度梯度与判分标注的评估任务集；② 指标与护栏硬阈值（含实验停规则）；
③ Rubric 设计（加权+一票否决）；④ 归因记录 schema 与首错定位方法；⑤ 回归与决策规则；
⑥ 落盘文件 `{{ARTIFACT}}`。
