# 00 · 使用说明（Agent 开发全程会话提示词包）

## 这是什么 / 不是什么

**是**：从《AI Agent 书》（ai-agent-book-zh）的 604 个知识对象里萃取的一组**会话提示词**——
你在开发自己 Agent 项目的各阶段开工前，替换占位符、整段粘贴，把书里的工程规则与反模式
变成这次会话的纪律、方法与自查清单。

**不是**：不是技能（不参与自动触发），不是规格文档。**诚实声明**：本包**不进门禁、不做盲测、
不做效用 A/B**——因此它不能声称与 `skills/` 下已发布技能同等的评测质量
（对照：6 个已发布 Agent 技能实测 4 passed / 2 low-utility）。它按「书里有支撑 + 逐条可回指对象 id」
的轻标准产出；每条规则/禁忌的来源对象在文件末尾逐条列出，可自行复核。

## 怎么用（三步）

1. **选模块 → 替换占位符**：每个文件第三节「粘贴正文」是一个 `text` 代码块，
   把其中的占位符替换成你的项目信息（见下表）。
2. **整段粘贴**：从代码块开头到结尾整段复制，粘贴到你的开发会话（Claude Code 等）开局。
3. **收尾**：会话结束前让 Agent 逐条过正文末尾的「收尾前逐条自查」；文件第四节
   「粘贴后你会拿到什么」列出本次会话应有的产物，缺项就追问。

**重复与边界**：同一模块可重复粘贴（比如工具设计分几次做）；**模块之间不要回粘**
（每个模块正文里都标注了「本模块不含」的边界，跨模块内容在各自归属处）。占位符规则：
每个占位符在正文中**恰好出现一次**，未被替换的 `{{` 说明你还没填完。

| 占位符 | 语义 | 出现范围 |
|---|---|---|
| `{{PROJECT}}` | 项目一句话（≤20 字） | 全部模块 |
| `{{STACK}}` | 语言/框架/运行时 | 01–10 |
| `{{AGENT_NAME}}` | Agent 名称 | 01 |
| `{{PRIOR}}` | 上一模块产物的路径 | 02–10（01 无上游） |
| `{{ARTIFACT}}` | 本模块要落盘的文件路径 | 全部模块 |
| `{{OWN_CONSTRAINT}}` | 项目自有硬约束（≤3 条，没有就删行） | 01 |

## 全局常驻片段

五条贯穿全书的设计模式（提议者—审核者 / 渐进式披露 / 只增不改 / 边界集+保留集 /
最小 diff+可回滚）与安全三层护栏口径，在 [`00-resident-snippet.md`](00-resident-snippet.md)：
把那段 `text` 块粘进你项目的 CLAUDE.md/AGENTS.md 一次即可，不必每会话粘贴。

## 与已发布技能的关系

**技能 = 模型侧自动触发的知识与工作流资产**（`skills/`，按 description 路由）；
**本提示词包 = 人侧主动粘贴的会话编排层**（开工仪式）。互不为前置：
各模块只在文件头以「可配套技能（可选）」提示对应技能，不要求安装、不复制技能正文。
三条防打架原则：① 提示词包不定义触发词、不复制技能的步骤/检查/产出；
② 技能不把提示词包当前置；③ 「可配套技能」列只引用已发布的 Agent 工程技能，
且同一技能最多出现在两个模块。
