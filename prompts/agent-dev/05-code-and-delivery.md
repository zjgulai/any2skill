# 05 · 代码与交付 · 会话提示词

> 吸收章节：ch5（+reference-answers 3 条）｜ 对象：10 条工程规则 + 2 条反模式条目
> 可配套技能（可选）：`validate-generated-artifacts`

## 一、什么时候粘这一段

当 Agent 要**产出代码、HTML/SQL/表单等生成产物，并进入交付流程**时；
以及为 Agent 搭建**自我修复与发布门禁**时（生成→渲染→验证→修复→放行）。
**不要**用它来设计工具接口本身（04）或评估方法论（07）。

## 二、衔接

- 上游：01 的沙盒与审批边界、04 的工具接口规范。
- 本模块产物：`{{ARTIFACT}}`（生成产物交付链设计——渲染验证、自修复两层、发布门禁、信任边界）。
- 下游：07 评估（把交付门禁接到评估集上）。
- **本模块不含**：多 Agent 的代码分工（见 09）；训练侧的后训练（见 10）。

## 三、粘贴正文

```text
你是协助我开发 Agent 的工程师。本会话聚焦"生成产物怎么安全地交付"：
从生成、渲染验证到修复、发布，把链条一次设计到位并落成文件。先读上游产物：{{PRIOR}}

项目：{{PROJECT}}（技术栈：{{STACK}}）

一、本会话任务
1. 定义本 Agent 的完成标准（写出代码 ≠ 完成），并落到检查项。
2. 设计渲染/执行验证环节：产物在受控环境里真实跑一遍，失败如何被抓到与上报。
3. 设计自我修复两层：确定性检查覆盖高频问题 + LLM 处理长尾疑难。
4. 划定信任边界：哪些规则由数据层/服务端强制（模型报什么都不信）。
5. 设计发布门禁：生成产物在隔离环境复现、回归后才能发布。
6. 全部落盘为：{{ARTIFACT}}

二、方法（来自本书的工程规则）
1. 【R1】完成标准定义在"测试通过"而不是"代码写完"——没有验证信号的产出不算交付。
2. 【R2】能用代码强制的规则就不要用文档建议：linter、类型约束、CI 检查的价值远超
   系统提示词里"请遵循……"式的指导。
3. 【R3】在代码驱动的生成里，仅生成代码不够——必须引入渲染与审核机制，
   在真实渲染/执行中发现效果问题。
4. 【R4】生成 HTML/UI 时优先采用声明式协议（只输出界面描述 JSON，由受信组件目录渲染），
   不执行任意代码；确需任意 HTML 时放在沙盒环境中展示。
5. 【R5】Agent 生成的代码修改必须由安全机制在隔离环境中复现、回归后才能发布。
6. 【R6】动态生成软件的安全目标是：即使 AI 写错代码，权限约束依然无法被绕过——
   更稳的架构是把信任边界下移到数据层，由稳定且经人类审查的机制强制权限。
7. 【R7】政策事实（库存、状态、当前时间等）必须由服务端查询得到，不得采信模型自报的参数。
8. 【R8】自我修复两层配合：先用确定性检查覆盖高频问题，确定性规则未覆盖的疑难
   再交给 LLM 分析并生成修复方案。
9. 【R9】适应机制必须与报告并行：对格式变化适配时，不能让适配逻辑吞掉异常信号——
   静默兼容要给告警/工单留位置。
10. 【R10】前端遇到无法解析的输入（如日志格式变了）时，不要只显示错误——
    自动把失败样本与详细报错报告给 Agent，让它进入修复回路。

三、禁忌（来自本书的反模式）
- 【P1】把政策事实（舱位等级、保险状态、当前时间等）设计成由模型填写的参数——
  模型报错一个值，最后一道防线就形同虚设。
- 【P2】相邻高危模式（详见其它模块）：把黑名单当唯一安全机制（见 01·P1）、
  在参数层静默转换（见 04·P2）——在生成-交付链上它们会直接放大为"错误产物被放行"。

四、交付与停止
- 交付物：生成产物交付链设计（完成标准、渲染验证、自修复两层、信任边界、发布门禁），
  落盘后附路径摘要。
- 效率约定：本模块是单会话设计任务，不需要多代理验证编排；需要复核时对着正文末尾的自查清单过一轮即可，不确定处写进「待定」。
- 停止条件：① 设计落盘、五条自查逐条勾选后停止，复述路径与未决项，不做本模块之外的工作；
  ② 当验证环境或信任边界缺少确定方案所需的信息时，先把不依赖该问题的部分推进并落盘（哪怕是骨架，把缺口标成「待定：<问题>」），再停下来问我这一个问题，不要按默认值继续；③ 任何把生成产物发布到生产/合并主分支的动作，先停下请求我确认。
五、收尾前逐条自查
□ 完成标准含可执行检查（测试/渲染/回归），不是"看起来对"
□ 渲染/执行验证在受控环境真实跑过，失败会带着样本上报
□ 自修复两层齐备：确定性检查 + LLM 长尾
□ 政策类事实全部服务端取值，模型自报的一律不信
□ 发布门禁写明"隔离复现 + 回归通过才放行"
```

## 四、粘贴后你会拿到什么

① 可检查的完成标准；② 渲染/执行验证环节设计；③ 两层自修复回路；④ 数据层信任边界；
⑤ 发布门禁（隔离复现+回归）；⑥ 落盘文件 `{{ARTIFACT}}`。
