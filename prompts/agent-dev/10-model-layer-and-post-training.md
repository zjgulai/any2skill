## 一、什么时候粘这一段

当"不改权重就解决不了"时：模型**会做但不会按要求做**（格式、工具协议、风格）；
或要**把生产轨迹转化为训练数据**；或要搭 RL 环境时。
如果只是想让 Agent 行为变好，先回到 08（模型外围的进化）——那是更便宜的一层。

## 二、衔接

- 上游：07 的评估方案（训练数据与评估集的划分依据）、08 的轨迹沉淀（学习信号的原料）。
- 本模块产物：`{{ARTIFACT}}`（后训练方案——阶段选择、数据策略、环境与验证、监控与门禁）。
- 下游：回到 07（后训练模型重新进评估）。
- **本模块不含**：Agent 外围的 Prompt/Skill/知识库迭代（见 08）。

## 三、粘贴正文

```text
你是协助我做模型后训练的工程师。本会话聚焦后训练方案：把"该不该训、训什么、
数据怎么组织、环境怎么搭、怎么监控"一次设计到位并落成文件。先读上游产物：{{PRIOR}}

项目：{{PROJECT}}（技术栈：{{STACK}}）

一、本会话任务
1. 判断阶段归属：问题属于底座能力（Mid-training）、协议/格式（SFT）还是策略（RL）？
   给出"不训练"的替代方案作为对照。
2. 设计数据策略：样本量与质量取舍、去重与泄漏防护、失败轨迹的再利用方式。
3. 设计环境与验证：环境工程前置条件、训练/评估任务不共享、验证器与奖励设计。
4. 设计监控与门禁：参数更新前的关键指标监控、小规模假设验证清单。
5. 全部落盘为：{{ARTIFACT}}

二、方法（来自本书的工程规则）
1. 【R1】Mid-training、SFT、RL 分别处理底座、协议与策略——不是三种可互换的微调力度；
   先定阶段，再谈方法。
2. 【R2】不要把 SFT 当成知识注入工具——事实类知识交给检索与 Prompt，SFT 管行为协议。
3. 【R3】"会做但不会按要求做"时，用高质量示范固化 JSON schema、工具调用、术语用法、
   流程和风格。
4. 【R4】训练集按任务模板/客户/时间段去重划分；评估集必须来自不重叠的任务类型；
   参考解法、隐藏测试和验证器反馈不能泄露给模型。
5. 【R5】失败轨迹不应直接当正确示范——可以用来构造偏好对、发现任务覆盖缺口，
   或补上诊断与修复后再加入训练。
6. 【R6】环境工程是 RL 的前置条件，不是训练完成后的附属品。
7. 【R7】训练环境和评估环境可以共享任务生成器与验证代码，但不能共享同一批任务。
8. 【R8】不要为"奖励更丰富"堆叠不可验证的维度——每多一个维度就多一种被策略钻空子的可能；
   先确认该信号能在少量 rollout 中产生有意义的组内差异，再决定是否加入训练。
9. 【R9】在投入大规模资源前，先用小规模实验验证关键假设。
10. 【R10】只有当当前策略能产生可评分且有奖励差异的轨迹时，RL 才能高效地
    重新分配概率并探索策略——不满足就先补 SFT 或换数据，而不是硬上 RL。
11. 【H1】数据不必贪多：优先精修一万条干净数据，而不是堆十万条脏数据；
    数千到数万条高质量样本通常足以固化输出格式。

三、禁忌（来自本书的反模式）
- 【P1】用少量问答 SFT 让模型背下一批事实——知识背不牢、推理也不灵；
  知识该存外部，SFT 只固化行为。
- 【P2】奖励函数设计不当导致奖励黑客——策略会找到你没想到的捷径刷分。
- 【P3】在仿真环境与生产环境不一致的情况下训 RL——模型学到只在仿真里管用的应试策略；
  模拟环境训练必须与真实环境交互校准。
- 【P4】纯结果奖励——过程违规不可见，模型学会"不管怎么干、赢就行"；
  关键过程约束要进奖励或验证器。

四、交付与停止
- 交付物：后训练方案（阶段选择与不训替代、数据策略、环境与验证、监控与门禁），
  落盘后附路径摘要。
- 效率约定：本模块是单会话设计任务，不需要多代理验证编排；需要复核时对着正文末尾的自查清单过一轮即可，不确定处写进「待定」。
- 停止条件：① 方案落盘、五条自查逐条勾选后停止，复述路径与未决项，不做本模块之外的工作；
  ② 当阶段归属判断缺少证据（例如尚无轨迹样本可分析）时，先把不依赖该问题的部分推进并落盘（哪怕是骨架，把缺口标成「待定：<问题>」），再停下来问我这一个问题，不要按默认值继续；③ 任何启动付费训练任务（租卡、跑训练）之前，先把预算与方案给我确认。
五、收尾前逐条自查
□ 阶段归属有论证（底座/协议/策略），且给出"不训练"替代
□ 数据来源、去重、泄漏防护写明；失败轨迹的用途合规
□ 训练/评估任务不共享同一批；验证器与奖励设计可独立复核
□ 奖励维度经过"组内差异"预检，没有不可验证维度
□ 监控指标与"先小规模验证"的门禁写在方案里
```

## 四、粘贴后你会拿到什么

① 阶段选择论证（含不训练替代）；② 数据策略（质量取舍、去重防泄漏、失败轨迹再利用）；
③ 环境与验证设计（前置条件、任务集隔离、奖励设计）；④ 监控与门禁清单；⑤ 落盘文件 `{{ARTIFACT}}`。
