# 32：Agent 开发全程提示词包（从书萃取会话提示词）

**要构建什么：**把《AI Agent 书》的知识对象（604 条，含 14 条跨章合成反模式）
再萃取一层为**开发会话提示词**——用户开发自己 Agent 项目时，各阶段开工前直接粘贴的
单段完整提示词（角色→任务→书·硬约束→书·禁忌→交付/停止→自查清单）。

**状态：**完成（2026-10-16）。产物：`prompts/agent-dev/`（10 模块 + 00 使用说明 +
常驻片段 + 覆盖表 + 未入选清单 + 分桶文件）。

## 决策（与用户对齐）

1. **两者都要**：批一=开发会话提示词（本卡）；批二=产品 Agent 系统提示词模板（待细化）。
2. **模块口径**：生命周期重组 10 模块，每模块标注吸收的书章节。
3. **形态**：单段完整、可直接粘贴；正文硬上限 3200 字。
4. **生成方式**：会话内撰写、**零外部模型调用**；条目附来源对象 id。

## 方法（轻流程四步）

1. 分桶：`chapter→module` 映射 + AP-SYNTH 单一归属 + reference-answers 显式分配
   （`prompts/agent-dev/buckets.v1.json`）。
2. 撰写：按对象字段映射（appliesWhen→何时用；statement→硬约束；violation/pattern+harm→禁忌；
   corrective→正确做法）；`appliesWhen` <15 字的对象限定词**编辑补写**并标注。
3. 核对：逐模块覆盖表（`COVERAGE.md`）+ 引用 id 全量可解析 + 占位符出现次数=1。
4. 收尾：README/playbook 指路 + 一次提交。
