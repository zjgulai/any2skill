# 06：反模式跨章综合（按主题组织输入）

**要构建什么：**让 `AntiPattern` 真正被产出——且必须以**跨章综合**的方式产出，而非从某一小节抄取。

为什么这一卡非独立不可（实测）：全书「常见陷阱」字面 **0 命中**；显式失败小节全书仅 **13 处**（chapter10 共 7、chapter5 共 1、chapter7 共 3、chapter8 共 2，其余章节 0）。而目标量级是 22 个 skill × 6–8 条 ≈ 130–176 条。差了一个数量级——不是抽得不够努力，是**原文里不存在**，必须由模型跨章归纳。

**被谁阻塞：**04

> **实施纪律：不预设数值阈值（Q13 已定）**
> 「什么算同一主题」与「跨章占比到什么水平算够」**本卡不预设阈值**。
> 理由：这两个量在产出前无法判断，凭空设一个数字会反过来逼着实现者去凑阈值、降低质量。
> 正确顺序是：先按跨章综合产出 → 从真实分布取数 → 再定阈值。因此本卡要求在首次全量产出后**输出真实分布供决策**，而不是在跑之前先立判据。

**状态：**ready-for-agent

- [ ] `AntiPattern` 的输入组织方式为**按主题**，而非按章节顺序；该组织方式在实现中显式可见
- [ ] 单个 `AntiPattern` 对象可携带**多个锚点**，以支持跨章结论（不得被迫假装只有单一出处）
- [ ] 一个反模式由多个章节共同支撑时，其 `sourceRefs` 指向**全部**相关章节，且引文均可逐字命中
- [ ] 同一主题在多个章节重复出现且 `corrective` **字段值完全相同**时，产出合并为一条而非多条（**判据取精确字段相等，不引入语义相似度阈值**；语义级去重待阈值确定后再议）
- [ ] 无跨章支撑的单章反模式被标记，理由码可区分（这是「抄取冒充综合」的检出点）
- [ ] 首次全量产出后，**输出真实分布供决策**：反模式总数、引用 ≥2 个章节的条数、跨章占比、被引用章节的分布
- [ ] **不设通过/不通过阈值**：本卡不以任何跨章占比门槛作为验收条件；分布数据交由用户在看过真实产出后决定阈值
