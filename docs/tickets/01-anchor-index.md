# 01：单文件确定性锚点索引（第 1 层）

**要构建什么：**从命令行传入一个内容源文件，得到一份该文件的**章节/小节锚点索引**并落盘。索引里每个锚点记录：它在文件内的稳定标识、标题层级、标题原文、起始行、结束行，以及该区间内容的哈希。

同一输入连跑两次，索引**逐字节相同**——这一层不使用 LLM，可复现性必须能当场证明，它也是全链路「可溯源」的物理底座：后续每个知识对象的 `sourceRefs` 都要指到这里。

### 一处口径说明（不是缺陷，是两套口径）
