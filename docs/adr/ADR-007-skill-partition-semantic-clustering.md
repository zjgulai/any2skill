# ADR-007 · Skill 划分策略：语义聚类派生，数量是结果而非配额

- 状态：已接受
- 日期：2026-10-08
- 决策者：用户（拍板「A」）
- 关联：ADR-001、ADR-003、ADR-004、ADR-006

## 背景

前六项决策定的是「怎么编译」；本项定的是**编译单元的边界从哪来**。

**先决约束（来自 ADR-001）**：原书 22 个 skill 位于 `benchmark/` **只读隔离区，禁止进入生成链路**。因此「照抄原书划分」在流程上**不可执行**——要拿到那 22 个边界就必须读 `benchmark/`，一旦读入，对照组失效。

因此真正的问题是：**自己按什么原则切，切出多少就接受多少，还是必须凑到某个数字。**

**可用的对照基准**：原书 22 个 skill / 10 章 ≈ **2.2 skill/章**（实测）。

**切分依据的性质**：两个 skill 该不该分开，取决于它们**是否回答同一类问题**——这是语义判断，不是计数。若把某个数字当配额，会人为制造「为凑数而拆出的伪 skill」，其触发场景高度重叠，正是 ADR-006 门禁二设计来捕获的缺陷。

## 决策

**纯语义聚类派生，数量不限：**

1. 确定性结构层产出小节锚点（ADR-005 第 1 层）。
2. LLM 逐节抽知识对象（ADR-005 第 2 层）。
3. 按「**同章 + 同问题空间**」把 5–15 个对象聚成**内容单元**。
4. 3–8 个内容单元聚成一个 skill（ADR-004 的分层）。
5. **2.2 skill/章 仅用于事后偏差诊断，不作切分目标。**

**让门禁反向修正划分，而不是让划分迎合数字：**

| 门禁二观测 | 判定 | 动作 |
|---|---|---|
| 同一场景被 ≥2 个 skill 争抢 | 粒度**太碎** | 合并相关 skill |
| 某 skill 的 `description` 无法覆盖其全部内容单元的触发场景 | 粒度**太粗** | 拆分该 skill |
| 某 skill 在盲测中零命中 | 该 skill 无独立触发场景 | 并入邻近 skill 或降级为 `references/` 章节 |

## 理由

- **与 ADR-001 的污染隔离逻辑自洽**：这是唯一不需要读 `benchmark/` 的选项。
- **切分质量可被证伪**：门禁二给出客观的过碎/过粗判据（上表），划分不必依赖人工审美。
- **原则可复用**：价值不在切出某个数量，而在切分原则能迁移到下一个信息源——这是 any2skills 要能「any」的前提。
- **收敛即证据**：若最终数量恰好接近 22，是**两条独立路径收敛**的最强信号；若差异很大，则是更有价值的信息——说明原书的划分隐含了我们尚未识别出的组织原则，值得专项分析。

## 被否决的方案

| 方案 | 否决理由 |
|---|---|
| 以原书 22 个的名字与边界为目标结构 | **与 ADR-001 直接冲突**：要拿到边界就得读 `benchmark/`，对照组失效。若改为「凭模型记忆复现」，则是用记忆冒充流水线产出——**属于编造**，违反本项目 AGENTS.md 第 8 条纪律。此选项在流程上不可执行 |
| 每章固定 1 个 skill（共 10 个） | 实测原书为 2.2/章。固定 1 个会把 `chapter2`（11 个 `##` 小节、130,806 字节，含 KV Cache / 提示工程 / 动态提示词与 Skills / Agent 状态栏 / 上下文压缩五块独立主题）压成单文件，必然超 ADR-004 的体积阈值；且 `description` 无法覆盖五个不相关主题，触发门禁必挂 |
| 先人工定 22 个 skill 名，再让流水线往里填 | 把「编译器」降级为「填空器」——划分环节的核心能力（判断哪些知识该聚成可复用单元）被人工预置，链路关键部分未被验证 |

## 后果

**正面**
- 划分可被门禁客观证伪，不依赖人工审美。
- 切分原则可迁移到其他信息源。

**负面 / 代价**
- 最终数量可能 ≠ 22，与原书不可逐一对齐。
- 跨章综合类 skill（如全书 `AntiPattern` 汇总）是否独立成 skill 需要额外判据。**约定**：若某跨章综合物能被 ≥3 个独立场景触发且不属于任何单章的主题，则独立成 skill；否则作为各 skill 的「常见陷阱」段内容分发。

**必须遵守的约束**
- 切分过程**不得读取** `benchmark/`。
- 划分结果必须记录**聚类依据**（哪些内容单元、因何聚在一起），使划分可复核。
- 若最终数量与原书 22 差异显著，**必须专项分析差异原因**，不得简单归因于「质量不够」。

## 核实方式

```bash
# 原书 22 个 skill / 10 章 = 2.2（实测）
curl -s https://api.github.com/repos/bojieli/ai-agent-book/contents/skills | jq -r '.[]|select(.type=="dir")|.name' | wc -l   # 22
ls sources/ai-agent-book-zh/book/chapter*.md | wc -l                                                                          # 10
# chapter2 的小节数与体积（支撑「固定 1 个不可行」）
grep -cE '^## ' sources/ai-agent-book-zh/book/chapter2.md   # 11
wc -c sources/ai-agent-book-zh/book/chapter2.md             # 130806
```
