仓库物理边界：skills/ 是只读发布区，只接收门禁一通过的产物；pipeline/knowledge 与 pipeline/registry 是中间态与证据面；sources/ 与 benchmark/ 只读，生成链路任何环节不得读取 benchmark/（污染隔离由每进程独立的 fs 账本反证：benchmark 内容访问 0、skills/ 写入 0，账本缺席/截断不得判通过）。写入分三类：draft（本地草案，无需批准）、write（nmem/环境写，必须在 G1 分域批准后执行）、verify（只读验收）。禁止删除或改写历史证据：旧产物归档 history，拒绝例移入 pipeline/registry/rejected 并写 REJECTION.md；判据/口径改动必须新增 ADR 或追加记录，不静默改写。密钥/凭据只经环境变量或 $DSH_HOME/.credentials.yaml 的 refs 读取，不写入仓库/记忆/回执。nmem 写入逐命令显式传空间：memories/library 用 --space any2skills，rules 用 --scope space --space any2skills，ontology 用 --scope space --space-id any2skills；禁止默认 global。
