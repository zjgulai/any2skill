# Rust泛型语法与代价

## 何时使用

- 在 Rust 中定义泛型函数、在函数签名中引入类型参数时。
- 当结构体中多个字段共用一个泛型参数时。
- 为泛型结构体 `Point<T>` 实现方法时。
- 为泛型结构体定义方法，且方法需要接收与 `self` 不同泛型版本的参数时。
- 当使用 Rust 泛型编写不重复的代码并运行时。

## 核心原则

**在函数签名中使用类型参数时，必须在使用之前先声明该类型参数；类型参数声明位于函数名称与参数列表中间的尖括号 `<>` 中。**

这样编译器才能知道类型参数的名字指代什么，就像函数参数需要先声明名字一样。

**在结构体定义中，如果多个字段使用了同一个泛型类型参数，那么这些字段必须具有相同的具体类型。**

结构体 Point<T> 对于一些类型 T 是泛型的，而且字段 x 和 y 都是相同类型的。

**为泛型 `Point<T>` 实现方法时，必须在 `impl` 之后声明泛型 `T`，这样 Rust 才会知道 `Point` 尖括号中的类型是泛型而不是具体类型。**

声明 `T` 后才能在 `Point<T>` 上实现的方法中使用该泛型参数，并让 Rust 识别 `Point` 尖括号中的类型为泛型。

**结构体定义中的泛型类型参数并不总是与结构体方法签名中使用的泛型是同一类型；方法可以获取与调用它的 `self` 不同的 `Point` 类型作为参数。**

方法 `mixup` 获取另一个 `Point` 作为参数，而这个参数可能与调用 `mixup` 的 `self` 是不同的 `Point` 类型。

**使用 Rust 泛型在运行时没有运行时开销，执行效率与手写每个具体定义的重复代码一样。**

Rust 为每一个实例编译其特定类型的代码，这个过程称为单态化。

## 实践模式

**std::cmp::PartialOrd trait**

标准库中定义的 trait，可以实现类型的比较功能，用于开启比较功能。

- `largest` 函数体需要比较 `T` 类型的值时，可由 `std::cmp::PartialOrd` trait 实现类型的比较功能。

**泛型结构体**

用尖括号语法定义的结构体，包含一个或多个泛型参数类型字段。

- 可以存放任何类型的 x 和 y 坐标值的结构体 Point。

**Option<T>**

一个拥有泛型 T 的枚举，有两个成员：Some 存放类型 T 的值，None 不存在任何值；可以表达有一个可能值的抽象概念，且因泛型而适用于任何类型。

- Some(T) 存放一个类型 T 的值
- None 不存在任何值

**Result<T, E>**

拥有两个泛型类型 T 和 E 的枚举，Ok 存放 T 型值，Err 存放 E 型值，用于表达可能成功返回 T 也可能失败返回 E 的操作。

- 打开文件成功时 T 对应 std::fs::File 类型
- 打开文件失败时 E 的值是 std::io::Error 类型

## 常见陷阱

- **在泛型函数体中直接使用需要特定 trait 支持的操作（如 `>` 比较），却不给类型参数添加相应的 trait bound。**
  - 后果：编译器会报错 `binary operation `>` cannot be applied to type `T``，函数无法编译，因为它不能保证所有 `T` 都能执行该操作。
  - 纠正：先明确函数体需要的 trait 行为，并为泛型参数添加对应 bound，例如 `fn largest<T: PartialOrd>(list: &[T]) -> T`；若需要移动值，再考虑 `Copy` 或返回引用。
- **用单个泛型参数 `T` 定义结构体，却希望各字段能接受不同的具体类型。**
  - 后果：实例化时所有字段都被绑定为同一个 `T`，传入不同类型会导致类型不匹配错误，无法表达两个字段独立类型。
  - 纠正：如果字段可以不同类型，应使用多个泛型参数，如 `struct Point<T, U> { x: T, y: U }`。
