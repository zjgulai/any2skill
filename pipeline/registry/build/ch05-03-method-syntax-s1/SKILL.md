# 方法语法全流程

## 何时使用

- 函数需要多个相互关联的输入来完成计算，例如用宽度和高度计算长方形面积。
- 函数参数是结构体实例，调用方需要在调用后保持所有权并继续使用该实例。
- 适用于在结构体上下文中定义的方法，也适用于枚举或 trait 对象的上下文。
- 在 impl 块中定义方法时。
- 在 Rust 中调用方法时。
- 调用结构体上的关联函数时。
- 当结构体较大，需要更易读的调试输出时

## 核心原则

**当函数需要接收多个彼此相关联的参数时，应把它们组合在一起，使函数签名体现这种关联，从而更易懂、更易处理。**

两个参数相互关联，但以独立参数形式出现时，程序本身无法表现出它们之间的关联。

**当函数接收结构体参数，且调用方需要在调用后继续使用该结构体时，应传入不可变借用而不是获取其所有权。**

借用可以保持调用方对该结构体实例的所有权，使调用方在函数调用后能继续使用它。

**方法第一个参数总是 `self`，它代表调用该方法的结构体实例。**

`self` 代表调用该方法的结构体实例。

**在 impl 块中定义方法时，方法的第一个参数必须有一个名为 self 的 Self 类型参数。**

因为 Self 类型是 impl 块的类型的别名，Rust 允许在第一个参数位置上只用 self 这个名字来缩写。

**Rust 没有与 `->` 运算符等效的运算符，而是使用自动引用和解引用功能。**

方法调用是 Rust 中少数几个拥有自动引用和解引用行为的地方。

**关联函数使用结构体名和 `::` 语法来调用。**

关联函数位于结构体的命名空间中，`::` 语法用于关联函数和模块创建的命名空间。

## 实践模式

**Rectangle**

一个包含 width 和 height 两个 u32 类型字段的结构体。

- 在 main 中创建的具体 Rectangle 实例，宽是 30，高是 50。

**Debug trait**

一个允许以对开发者有帮助的方式打印结构体，以便调试时查看其值的 trait。

- 使用 `println!` 宏并传入 `{:?}` 格式指示符，如 `println!("rect1 is {:?}", rect1);`

**can_hold 方法**

`can_hold` 方法获取另一个 `Rectangle` 的不可变借用作为参数，返回布尔值，并分别检查 `self` 的宽高是否都大于另一个 `Rectangle`。

- `rect1.can_hold(&rect2)` 传入了 `&rect2` 作为参数

**不可变借用**

当方法只需要读取参数而不写入，并希望调用者保持该值的所有权以便在调用后继续使用时，使用不可变借用作为参数。

- `rect1.can_hold(&rect2)` 传入了 `&rect2`，它是 `rect2` 的不可变借用

**关联函数**

在 impl 块中定义的、与 impl 后命名的类型相关的函数；可以不以 self 为第一参数，因而不作用于结构体实例，不是方法。

- String::from 是在 String 类型上定义的关联函数。

**多个 impl 块**

Rust 中每个结构体都允许拥有多个 impl 块；示例 5-16 中每个方法可以有自己独立的 impl 块。

- 示例 5-16 使用多个 impl 块重写示例 5-15，每个方法有其自己的 impl 块。

## 常见陷阱

- **用元组索引表示宽高这类有业务含义的值，却不在代码中表达数据意义**
  - 后果：使用者必须牢记 `width` 的元组索引是 `0`、`height` 的元组索引是 `1`；数据意义没有被表达，容易忘记或混淆宽高而造成错误
  - 纠正：让代码表达数据意义，避免只靠元组索引区分宽高
