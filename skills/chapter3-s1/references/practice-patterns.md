溢出至此；SKILL.md 保留 6 段骨架与该段的加粗小节头 + 指针。内容来源与 SKILL.md 同批对象。

**知识库**

面向所有用户共享的集体知识。

- 一个行业的法规体系
- 一家公司内部的操作流程
- 一个技术领域的专业文档

**用户记忆提取**

对话结束后，Agent 框架调用一次专门的 LLM 分析对话内容，提取值得长期记住的信息。

- 用户偏好靠窗座位
- 用户是素食者，飞行时需要特殊餐食
- 用户的美联航会员号 12345678
- 用户有去东京的旅行计划

**第一层：基础回忆**

记忆系统最根本的能力，要求 Agent 能够准确存储和检索用户直接提供的、结构化的、无歧义的信息；这一层级确保记忆系统的基本可靠性，是后续更复杂能力的基础。

- 如 “我的会员号是 12345”，在后续需要时精确返回。

**第三层：主动服务**

衡量 Agent 是否达到“助理”水准的最高标准，要求系统综合来自多个会话、甚至很久以前的信息，提供具有预见性的主动帮助，从看似无关的记忆中发现深层联系，并在没有明确指令的情况下主动规避潜在问题和整合复杂信息。

- 预订国际航班时主动关联数月前存储的护照信息，发现即将过期并发出预警。
- 手机损坏时主动整合所有保障方案（手机自带的保修、信用卡附加保修条款、运营商保险），为用户提供完整的解决方案选项列表。
- 报税季主动从过去一年的记录中搜寻并整合所有税务文件（股票销售、自由职业收入、房产税），呈现完整待办清单。

**轨迹**

轨迹是一次 Agent 运行过程中的完整历史记录，按时间顺序排列，只增不改，用于追溯、调试或审计的原始事件记录。

- 用户消息
- 模型回复
- 工具执行结果

**用户长期记忆**

用户长期记忆是跨会话、跨实例的持久化存储，通常以键值对形式与特定用户 ID 绑定，存储偏好设置、历史交互摘要和提取的知识点，属于跨会话提炼出的稳定信息，会被反复改写、合并、淘汰。

- 偏好设置
- 历史交互摘要
- 提取的知识点

**User as Code**

一种把用户状态改成带类型的可执行对象、把规则写成普通函数，让表示和推理使用同一种可验证介质的做法。

- 把用户状态改成带类型的可执行对象
- 把规则写成普通函数

**情景记忆**

关于具体事件和经历的记忆

- 上周三和同事在那家意大利餐厅吃了一顿很棒的晚餐
- 前面订机票例子中的“用户订了下周五去东京的 ANA 航班”——记录了一个具体事件的时间、对象和细节

**语义记忆**

从具体事件中抽象出的一般性知识

- 意大利的首都是罗马
- “用户是素食者”、“用户偏好靠窗座位”——这些不是某次对话的记录，而是从多次交互中提炼出的稳定特征

**Mem0 v3**

Mem0 v3 是当前记忆管线：写入时用一次 LLM 调用抽取事实并只做 ADD，查询时融合语义相似度、BM25 关键词和实体匹配并结合时间信息排序。

- 用户先说“我住在北京”，后来又说“我搬到了上海”时，两条事实带时间信息并存，而不是更新前一条。

**Memobase**

Memobase 是一个聚焦“用户画像”的开源记忆管理项目，将用户记忆组织为用户画像和事件记忆两部分；工程上采用缓冲批处理策略，在对话累积到一定规模或时限后统一触发记忆提取。

- 用户画像按主题—子主题两级组织，如 basic_info→姓名、interest→兴趣偏好、work→职位。
- 事件记忆按时间线记录用户经历的事件，用于回答“我们上次讨论预算是什么时候”这类与时间有关的问题。

**重要性评分筛选**

综合访问频率、时间衰减、情感强度和信息独特性四个因素评估记忆的重要性，低于阈值的记忆标记为可压缩或可删除

- 一条被访问 5 次、创建于 3 天前、带有强情感标记、且无重复记录的记忆会获得较高的重要性得分
- 一条仅被访问 1 次、创建于 90 天前、无情感标记、且与其他 3 条记忆高度重复的记忆则可能低于压缩阈值

**PII 检测与脱敏**

通过 Ollama 调用本地 Qwen3 0.6B 小模型实现 PII 检测与脱敏，可在 CPU、消费级设备上运行，也可按需切换到 qwen3:1.7b、qwen3:4b 等更大规格。

- Qwen3 0.6B 小模型
- qwen3:1.7b、qwen3:4b 等更大规格

**文件系统范式**

一种知识组织哲学，不将上下文视为扁平的向量碎片或图谱节点，而是将所有上下文——记忆、资源、技能——映射为虚拟文件系统中的目录和文件，每个条目拥有唯一 URI。

- viking:// 下的 resources/、user/memories/、agent/skills/、agent/memories/ 等目录

**判决因子重要性层次模型**

一种数据驱动的模型，通过将案件信息转换为数字格式、借助聚类算法发现自然的案件原型，并通过分析定义聚类的关键特征而构建。

- 轻微口角引发的徒手斗殴致人轻伤
- 有预谋的团伙持械围殴致人重伤

**多模态记忆**

对一张脸的模样、一个人的嗓音等难以用文字描述、且无法由文本记忆机制存储的信息的记忆；如何存储此类多模态记忆仍处于学术界前沿。

- 一张脸的模样
- 一个人的嗓音
